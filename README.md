# Abracadabrax for Claude

AI images, videos and songs from a conversation. Each plugin connects Claude to a hosted Abracadabrax MCP server with an interactive panel where you review the settings and the credits required before anything is generated.

| Plugin | What it does | Install |
|---|---|---|
| [Abracadabrax Image & Video](abracadabrax-image-video) | AI images and videos from a text prompt | `/plugin install abracadabrax-image-video@abracadabrax` |
| [Abracadabrax Song Maker](abracadabrax-song-maker) | Full songs with vocals, or instrumentals, from a style brief and lyrics | `/plugin install abracadabrax-song-maker@abracadabrax` |

```
/plugin marketplace add abracadabrax-app/claude-plugins
```

## Requirements

Preparing a request is free and works without an account. Generating asks you to sign in to [Abracadabrax](https://abracadabrax.app) (OAuth with PKCE) and uses the credits of your account; every generation shows its credit cost first.

**AI generation:** the images, videos and songs are generated by AI models run by Abracadabrax and its model providers, only when you ask for it.
